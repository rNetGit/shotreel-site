# ShotReel website

The public website for ShotReel, a free offline Windows app that turns screenshots and clicks into narrated training videos, captions and PDF step guides.

Static HTML and CSS, served by GitHub Pages from the `main` branch. No outside scripts.

`tools/build.py` writes `index.html`, `install.html` and `faq.html`; bump `VER` there for each new release. The app itself is at https://github.com/rNetGit/ShotReel-app.
