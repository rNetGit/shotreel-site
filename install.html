Download

Get ShotReel 2.2.0

For Windows 10 and 11, 64-bit. The installer is code-signed (publisher: Rajesh Katukojwala).

Installer A normal install, per user, no admin rights needed. About 585 MB to download.

All versions and notes are on the release page.

Install

  1. Download

    Download the installer. About 1.5 GB is used once it is installed, because the voice model, renderer and video tools are bundled.

  2. Run it

    Double-click the file. If Windows shows a blue SmartScreen notice, that is normal for a new publisher's first downloads: choose More info, then Run anyway. The signature below lets you check who published it.

  3. Make a video

    Start a project, capture a web or desktop app or import screenshots, write the steps, and choose Export. You get an MP4, captions and a PDF guide.

  4. Updating from 2.0 or 2.1?

    Install over the old version; your projects stay where they are. Updating is recommended: 2.2.0 renders fully offline (see the privacy answers).

Check the download

Not required, but quick, and worth doing on a work PC.

Check the file's SHA-256

Download SHA256SUMS.txt from the release, then in PowerShell (from the folder with the file):

Get-FileHash .\ShotReel-Setup-2.2.0.exe -Algorithm SHA256

The hash must match the line for that file in SHA256SUMS.txt.

Check the signature

Right-click the file, choose Properties, open the Digital Signatures tab and select the signature, then Details. It should say the signature is OK and name the publisher Rajesh Katukojwala. If the tab is missing, the file is not signed: do not run it.

Read the licence first

The EULA and the third-party notices are in the repository and in the download.

If something goes wrong

Windows blocked it or my antivirus complains

Check the SHA-256 and the signature above. If both are right, the file is the one we published. If your IT team scans downloads, send them the release page and the licence.

A long video renders slowly

Rendering uses the CPU, so length and 1080p both add time. Unchanged parts are not re-rendered, so the second export of a project is much quicker than the first.
